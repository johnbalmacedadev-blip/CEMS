# Pricelist

The **Pricelist** (`/pricelist`) shows vehicle pricing and financing options across inventory — purchase price, posted price, sold price, and computed financing plans.

## Access

- **Home category:** CAR REPORTS → **PRICELIST**
- **URL:** `/pricelist`
- **Permission:** `pricelist` → **view**

## Features

- Filter by status, search text, and year range
- View and edit financing details per vehicle
- Bulk update financing across vehicles
- Set posted price to 10% markup (bulk action)
- Export to PDF

## Status filtering

Pricelist respects the same status rules as Unit Report — **archived units are excluded** from active listings.
